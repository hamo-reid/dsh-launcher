# DSH Launcher v0.1.4

### 中文版

#### ✨ 功能
- **DSH 版本更新**：对 app 管理的 DSH 检查并原地升级；更新前自动备份 home；跨大版本需二次确认。
- **latest / next 双轨道更新检测**：区分稳定版与预发布 `next`；已是最新稳定版时可单独升级到 next。
- **官方安装版本下拉标签**：版本下拉以 Tag 标注 `latest`（稳定）与 `next`（预发布）。
- **Profile 跨版本迁移**：复制 profile 到另一 DSH 版本并按其 bundle 重建，源 profile 保留。
- **DSH 数据导出 / 导入 / 迁移**：导出某 DSH 的 profiles 与 home 用户数据为 zip 归档，可从归档恢复，或在已装版本间直接迁移。
- **关闭行为询问**：关闭时弹窗选择「最小化到任务栏 / 退出」，可勾选不再提示；设置页新增「关闭时总询问」开关与默认关闭行为。
- **托盘实时状态监控**：运行中托盘 tooltip 实时显示状态，右键菜单显示运行中 profile 与运行时长。

#### 🏗️ 工程 / 优化
- 版本比较改用 `semver` 库（原生支持预发布比较）。

### English

#### ✨ Features
- **DSH version updates**: check and in-place upgrade an app-managed DSH; home is auto-backed up first; cross-major requires a second confirmation.
- **latest / next dual-track update detection**: distinguish stable from the prerelease `next`; upgrade to `next` separately even when on the latest stable.
- **Official-install version-dropdown tags**: the version picker tags `latest` (stable) and `next` (prerelease).
- **Cross-version profile migration**: copy a profile into another DSH version and rebuild its bundles there; the source profile is kept.
- **DSH data export / import / migration**: export a DSH's profiles + home user data to a zip, restore from an archive, or migrate directly between installed versions.
- **Close-behaviour prompt**: closing asks "minimize to taskbar / quit" with a remember option; Settings adds an always-ask toggle and the default close behaviour.
- **Live tray status monitoring**: the tray tooltip shows run state in real time; the context menu shows the running profile and elapsed time.

#### 🏗️ Engineering
- Version comparison now uses `semver` (native prerelease support).
