# DSH Launcher v0.2.0-beta2

### 中文版

#### ✨ 功能
- **日志与诊断升级**：改用 winston，控制台按级别着色并按领域（domain）打标，文件按日轮转保存 JSON；启动时打印品牌横幅，渲染层 console 转发到主进程；Debug 模式实时追踪 pnpm 安装进度，并为 combo、market、node-env、store-install 等核心路径补充诊断。

#### 🐛 修复
- **从启动器运行的 dsh 打开编辑器 / 配置文件无反应**：bundled（Electron-as-node）路径下 `ELECTRON_RUN_AS_NODE` 会泄漏进 dsh 派生的子进程，被继承后导致 VS Code / Cursor 等编辑器和「设置 → 打开配置文件」以 Node 模式静默退出。现在 dsh 入口通过内联 `data:` 预载清除该变量，Electron 自身仍以 Node 模式启动；system Node 路径则不注入该变量，也不加载预载。pnpm 采用同一启动约定，其生命周期子进程同样干净。

#### 🏗️ 工程
- 所有 IPC handler 统一经过一个带审计的 wrapper（`handle.ts`），并在退出时报告所运行的 profile。
- 渲染层适配 antd v6 API 并修复列表 key。
- 新增提交信息规范（`docs/COMMITTING.md`）。

### English

#### ✨ Features
- **Logging and diagnostics**: switch to winston with level-coloured console output and domain tags, plus daily-rotated JSON files; a branded startup banner and renderer console forwarded to main; live pnpm install tracing and added diagnostics across core paths (combo, market, node-env, store-install) under Debug.

#### 🐛 Fixes
- **Opening an editor or the settings document from a launcher-run dsh did nothing**: on the bundled (Electron-as-node) path `ELECTRON_RUN_AS_NODE` leaked into processes dsh spawned; once inherited, Electron editors such as VS Code / Cursor — and the settings document handoff — started in Node mode and exited silently. dsh now clears the variable with an inline `data:` preload before its own code runs, while the Electron process still boots as Node; the system-node path sets neither the variable nor the preload. pnpm uses the same launch contract, so its lifecycle children are clean too.

#### 🏗️ Engineering
- Every IPC handler now goes through one audited wrapper (`handle.ts`), and the launched profile is reported on exit.
- Renderer adopts antd v6 APIs and fixes list keys.
- Added commit message conventions (`docs/COMMITTING.md`).
