# DSH Launcher v0.1.3

### 中文版

#### ✨ 功能
- **Node 运行时检测与选择**：启动前检测系统 Node 及其版本；可在「设置 → 运行环境」或首次安装引导中选择用系统 Node 或内置 Node 启动 dsh。
- **系统托盘后台运行**：点击关闭默认为最小化到系统托盘继续后台运行（可在设置改为直接退出）；托盘右键菜单含运行状态、显示 / 隐藏、退出。
- **覆盖率工程化**：为 core 模块增设覆盖率门槛（>70%），补齐 200+ 单元测试，核心代码覆盖从 ~43% 提升至 ~90%。

#### 🐛 修复
- **无系统 Node 也能启动**：将内置 Electron Node 升级到 24，修复低版本 Node 缺少 `node:zlib` zstd / `node:module` type-strip API 导致的启动崩溃。
- **dsh HMR 服务**：补齐 `--expose-internals` 启动参数，修复 web 类型 profile 启动即退出的问题。
- **运行输出乱码**：改为数组参数直接 spawn，去除 cmd / powershell 中转，管道固定 UTF-8，修复中文回显 GBK 乱码。
- **安装残缺检测与修复**：官方安装后做可用性校验，DSH 页对残缺安装提供「重新安装」（强制覆盖）；pnpm 增加网络重试（`--fetch-retries=3`）。

#### 🏗️ 工程 / 优化
- 统一内嵌运行时启动为「数组参数 + 无 shell」，消除对系统 shell 与系统 Node 的依赖。
- Electron 33 → 40 升级（内置 Node 24.15）。

### English

#### ✨ Features
- **Node runtime detection & selection**: detect the system Node (and its version) before launching; choose system vs bundled Node for running dsh from Settings → Runtime or the first-run onboarding wizard.
- **System tray / background run**: clicking close now minimizes to the system tray and keeps running by default (switchable to quit-on-close in Settings); the tray context menu shows running status, show/hide, and quit.
- **Coverage engineering**: added a >70% coverage gate for core modules; 200+ unit tests; core coverage raised from ~43% to ~90%.

#### 🐛 Fixes
- **Runs even without a system Node**: bundled Electron Node upgraded to 24, fixing a startup crash caused by old Node missing the `node:zlib` zstd / `node:module` strip-types APIs.
- **dsh HMR service**: added the `--expose-internals` flag so web profiles no longer exit on startup.
- **Mojibake console output**: launch via array args + no shell (no cmd/powershell hop), pipe fixed to UTF-8.
- **Broken installs detected & repairable**: official installs are validated after install; the DSH page offers "Reinstall" (forced overwrite); pnpm network retry added (`--fetch-retries=3`).

#### 🏗️ Engineering
- Unified the embedded runtime launch to "array args + no shell", removing dependency on the system shell and system Node.
- Electron 33 → 40 upgrade (bundled Node 24.15).
